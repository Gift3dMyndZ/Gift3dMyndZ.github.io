# Joshua Wolfe Platform Engineering Command Center

Foundation for a live engineering resume built with React 19, TypeScript, Vite, TanStack Query, and React Router.

## Start locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run typecheck
npm run lint
npm run build
```
